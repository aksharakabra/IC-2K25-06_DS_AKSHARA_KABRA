<h3>LINKED-LIST</h3>
Linked list is a organization of nodes where nodes is a self referential structure (SRS) with 2 components<br>
1. Info (data items to be stored in a list)<br>
2. Next (A pointer variable that stores the address of next node)<br>
<hr>
<h3>Stored in non continuous memory location.</h3><hr>

  <tr><th>Info</th><th>Next</th></tr>
</table>
<h3>NOTES</h3>
<pre>The end node's next contains null value
Linked list can have loops/ cycle which can be found by floyd's method
In loop the last node contains the address of any previous or its own address
linked list can be made by stack, queue, list etc</pre>
